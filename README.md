# OCCT_XCAF_FacePicker

`f3d --watch` but also query xcaf face data on left mouse clicks. Once the convention the RGB will instead be a jump-to-definition for in https://github.com/aavogt/rapids

```
apt install libglfw3-dev cmake 'libocct-*' occt-misc g++
cmake -Bbuild && cmake --build build
build/OCCT_XCAF_FacePicker model.step
